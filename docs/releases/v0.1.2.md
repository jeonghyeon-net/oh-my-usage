# v0.1.2 — 초기화 시간 표시와 메뉴 정렬

계정 메뉴에서 초기화권 앞에 다음 주간 초기화 시간을 표시하고, 메뉴와 메뉴바의 간격·정렬을 개선했습니다.

## 변경 사항

- `초기화 10/3 (토) 14:30  ↻ 1`처럼 주간 초기화 날짜·요일·시간을 표시합니다. Mac의 현재 시간대를 사용하고 시각이 없으면 `초기화 —`를 표시합니다.
- 계정 메뉴의 사용량·요금제·이메일·초기화 시간·초기화권을 공통 열에 배치합니다. 사용량과 초기화권 숫자는 오른쪽 정렬합니다.
- 메뉴바의 잔여율과 요금제 사이에 간격을 두고, 로딩·활성 계정·오류 표시가 바뀌어도 너비를 유지합니다.

## 설치

Apple Silicon, macOS 14 이상과 설치된 Codex 앱이 필요합니다. `oh-my-usage-0.1.2-arm64.dmg`를 열어 앱을 Applications에 복사하세요. 기존 앱이 실행 중이면 종료한 뒤 교체하고 다시 실행합니다. 저장된 계정은 유지됩니다.

앱은 ad-hoc 서명입니다. Developer ID 서명과 Apple 공증은 하지 않았습니다. SHA-256 파일은 내려받은 DMG가 같은 파일인지 확인하는 데 사용합니다.

## 검증

2026-09-30, macOS 27.0 / Apple Silicon에서 확인했습니다.

- `make check`, `make package` 통과
- 시간대와 날짜 경계, 누락되거나 잘못된 초기화 시각 검증
- 메뉴 열 간격·숫자 정렬·한글·누락 값을 창 없이 텍스트 레이아웃과 이미지 그리기로 검증
- 메뉴바 10,192회 렌더링: 계정 1–3개, 밝은/어두운 색상, 활성 상태, 시작 상태, 1x/2x
- DMG 무결성과 SHA-256 검증, 마운트 내용 확인: 앱과 Applications 링크
- DMG에서 임시 위치로 복사한 앱의 서명, 버전, 전체 파일 일치 확인

실제 팝업에서의 마우스·키보드 동작, 실제 계정 전환·로그인·로그인 시 자동 실행, macOS 14–26에서의 동작은 이번 릴리스에서 재검증하지 않았습니다.
