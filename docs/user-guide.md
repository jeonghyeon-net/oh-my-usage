# 사용 안내

## 계정 추가와 전환

메뉴바를 클릭하거나 우클릭하면 macOS 기본 메뉴가 열립니다.

| 메뉴 | 동작 |
| --- | --- |
| 현재 Codex 계정 추가 | 현재 `~/.codex/auth.json`의 로그인을 등록합니다. |
| 다른 계정 추가… | 기본 브라우저에서 OpenAI에 로그인합니다. 최대 3개까지 등록합니다. |
| 계정 행 클릭 | Codex 앱을 정상 종료하고 선택한 인증 파일을 적용한 뒤 다시 실행합니다. |
| 계정 삭제 | 이 앱에 저장한 계정과 해당 로그인 폴더를 제거합니다. |
| 새로고침 | 사용량을 즉시 다시 조회합니다. 평소에는 60초마다 갱신합니다. |
| 로그인 시 자동 실행 | macOS 기본 로그인 항목을 등록하거나 해제합니다. |

노란색 메뉴바 행과 메뉴의 체크가 현재 Codex 인증 파일에 해당하는 계정을 나타냅니다. 앱을 `/Applications`에 설치한 뒤 자동 실행을 설정하세요. 승인이 필요하면 시스템 설정이 열립니다. 체크 표시는 macOS에 등록된 실제 상태를 따릅니다.

계정 전환 전에 진행 중인 Codex 작업을 마치세요. 정상 종료에 실패하면 인증을 바꾸지 않으며 Codex를 강제 종료하지 않습니다. 계정 전환은 같은 인증 파일을 사용하는 CLI에도 적용됩니다. 계정을 삭제해도 Codex에서 로그아웃되거나 구독이 취소되지는 않습니다.

## 숫자 읽기

- `%`는 **주간 한도 중 남은 비율**입니다. 5시간 한도나 사용한 비율이 아닙니다.
- 1% 미만으로 조금 남아 있으면 `<1%`, 서버에 해당 값이 없으면 `—`입니다.
- 메뉴의 `↻ 1`은 사용 가능한 초기화권 개수입니다. 초기화권을 사용하는 기능은 없습니다.
- 계정 행에 마우스를 올리면 초기화 시각, 마지막 갱신 시각 또는 오류를 볼 수 있습니다.
- 조회 오류가 발생하면 메뉴바에 `!`가 표시됩니다. 기존 숫자는 마지막으로 성공한 조회 값일 수 있습니다.

`Pro $100`, `Pro $200`은 서버의 `prolite`, `pro` 구분에 사용하는 요금제 이름입니다. 실제 청구 금액·지역별 가격·프로모션 배수를 조회하지 않습니다. 다른 요금제도 표시하지만 제공되는 주간 한도와 초기화권 정보는 계정별로 다를 수 있습니다.

<a id="storage"></a>

## 데이터와 삭제

| 위치 | 내용 |
| --- | --- |
| `~/Library/Application Support/oh-my-usage/accounts.json` | 계정 식별자, 이메일, 요금제 목록 |
| `~/Library/Application Support/oh-my-usage/<UUID>/auth.json` | 계정별 OAuth 인증 토큰 |
| `~/Library/Application Support/oh-my-usage/switch-backup.json` | 계정 전환 시 복구용 인증 백업 |
| `~/.codex/auth.json` | Codex가 실제로 사용하는 메인 로그인 |

계정 폴더는 공식 CLI의 별도 홈으로도 사용되므로 CLI가 부가 파일을 만들 수 있습니다. 인증 파일은 평문이며 권한은 `0600`, 이 앱이 생성하는 폴더 권한은 `0700`입니다. Keychain이나 별도 암호화를 사용하지 않습니다. 이 경로를 Git, 이슈, 공개 클라우드 링크로 공유하지 마세요.

앱을 완전히 지우려면 자동 실행을 끄고 메뉴의 **종료**로 닫은 뒤 Applications의 앱과 위 Application Support 폴더를 삭제합니다. Codex 자체 로그인을 유지하려면 `~/.codex`는 삭제하지 마세요. 앱이나 DMG를 삭제하는 것만으로 저장된 계정이 지워지지는 않습니다.

<a id="compatibility"></a>

## 호환성과 제한

- Apple Silicon, macOS 14 이상을 빌드 대상으로 합니다. 모든 macOS 버전에서 수동 검증한 것은 아닙니다.
- 설치된 Codex 앱의 공식 CLI를 우선 사용합니다. 앱 식별자는 `com.openai.codex`입니다.
- ChatGPT 파일 기반 인증만 지원합니다. Keychain 전용 인증, `cli_auth_credentials_store="auto"`, API 키 로그인, 사용자 지정 `CODEX_HOME`은 지원하지 않습니다. 앱이 이 설정을 자동 변경하지 않습니다.
- 프로토콜 구현 기준은 Codex 앱 `26.924.22138`, CLI `0.158.0-alpha.2.1`입니다. 이후 버전의 응답 변경으로 호환성 문제가 생길 수 있습니다.
- 계정 전환 후 인증 파일의 계정 일치를 확인합니다. Codex 내부 화면의 로그인 상태까지 확인하는 공개 API는 사용하지 않습니다.
- 메뉴바 높이는 macOS가 정합니다. 3계정 표시는 최대 32pt 높이를 사용하며 낮은 메뉴바에서는 글씨가 작아집니다.
- 시작할 때 첫 사용량 조회와 메뉴바 배치가 끝날 때까지 같은 크기의 빈 공간을 유지한 뒤 표시합니다.

사용량이 보이지 않으면 메뉴의 오류를 확인하고 Codex에서 로그인이 유효한지 확인하세요. 재현 가능한 문제는 [버그 제보](https://github.com/jeonghyeon-net/oh-my-usage/issues/new/choose)에 환경과 재현 순서를 적어 주세요. 실제 계정 파일이나 이메일은 필요하지 않습니다.
